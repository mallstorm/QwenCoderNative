# Qwen Coder Native v4.0

Нативный Android-клиент Qwen Coder (coder.qwen.ai) с чатом в стиле Claude / ChatGPT. Работает напрямую с API сервиса, без WebView.

## Возможности
- Задачи в боковой панели (группы «Сегодня / Вчера / …»), открытие истории, удаление долгим нажатием.
- Выбор репозитория и ветки: список подключённых в Qwen Coder репозиториев с поиском, статус GitHub, обновление веток, запоминание выбора.
- Выбор модели прямо в чате (Qwen3-Coder, Qwen 3.8 Max, Qwen 3.8 Flash или свой ID).
- Стрим ответа, markdown, подсветка кода, карточки действий агента (команды, правки) с выводом.
- Голосовой ввод (ru-RU), превью проекта и страница задачи в браузере.

## Вход
Нужен `refresh_token` с coder.qwen.ai: F12 → Application / Приложение → Cookies → `.qwen.ai` → `refresh_token`. Токены хранятся только на телефоне.

## Подпись и обновление поверх
Все сборки подписываются одним постоянным ключом (`app/qc-release.jks`), поэтому новая версия ставится поверх старой без удаления. Ключ лежит в публичном репозитории: это удобно для личного приложения, но для публикации в магазинах такой ключ использовать нельзя.

## Сборка
GitHub Actions собирает подписанный release APK и публикует его в Releases.
