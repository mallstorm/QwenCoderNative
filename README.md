# Qwen Coder Native v5.1

Нативный Android-клиент Qwen Coder (coder.qwen.ai) с чатом в стиле Claude / ChatGPT. Работает напрямую с API сервиса, без WebView.

## Возможности
- Задачи в боковой панели (группы «Сегодня / Вчера / …»), открытие истории, удаление долгим нажатием.
- Выбор репозитория и ветки: поиск, дата последнего коммита, сравнение ↑/↓ с основной веткой, приблизительная дата первого уникального коммита, русская справка по затронутым файлам и сообщениям коммитов. История публичных репозиториев загружается из GitHub REST (без передачи Qwen-токенов); приватные используют только доступные метаданные Qwen. Даты создания ветки Git не гарантирует.
- Выбор модели прямо в чате (Qwen3-Coder, Qwen 3.8 Max, Qwen 3.8 Flash или свой ID).
- Стрим ответа, markdown, подсветка кода, карточки действий агента (команды, правки) с выводом.
- Окно кода (правая шторка): diff изменённых файлов, терминал агента, превью проекта.
- Уведомление, когда задача завершилась в фоне; переключатель «Думать»; остаток кредитов; настройки Qwen Coder; поиск, фильтр «Идут», закреплённые.
- Темы (тёмная, белая, бирюзовая), масштаб текста, окно выбора модели, экран настроек. Кнопка «/» в редакторе закреплена у нижнего края даже при многострочном вводе.
- Голосовой ввод (ru-RU), превью проекта и страница задачи в браузере.
- Независимые аккаунты Qwen: только ручное переключение, без проверки чужих кредитов, без автоматического выбора после выхода. Выбранный репозиторий/ветка хранятся отдельно для каждой сессии.
- Мгновенное уведомление о готовности задачи (WebSocket уведомлений, опрос как запасной вариант).
- Правка и повтор сообщения, ответ «заново», переключатель веток «‹ 1/2 ›».
- Кнопка «Создать Pull Request», приём текста из других приложений («Поделиться» → Qwen Coder).
- Шаблоны запросов и команды /fix /review /tests …, экспорт чата в Markdown, поиск по файлам из песочницы и отправка/сохранение файла.
- Блокировка приложения PIN/биометрией: утверждённая растровая иллюстрация ночной студии архитектора в верхней части экрана, без логотипов. Скриншоты разрешены и при включённой блокировке; не публикуйте снимки со своими токенами.

## Вход
Нужен `refresh_token` с coder.qwen.ai: F12 → Application / Приложение → Cookies → `.qwen.ai` → `refresh_token`. Токены хранятся только на телефоне.

## Подпись и обновление поверх
Все сборки подписываются одним постоянным ключом (`app/qc-release.jks`), поэтому новая версия ставится поверх старой без удаления. Ключ лежит в публичном репозитории: это удобно для личного приложения, но для публикации в магазинах такой ключ использовать нельзя.

## Сборка
GitHub Actions собирает подписанный release APK и публикует его в Releases.
